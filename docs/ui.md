# UI

## Policy

### Layout

- The application targets mobile devices only, despite being a web application.
- A minimum width constraint is applied so that it remains usable on PC without stretching to full width.
- Single-column layout.

### Design

- Buttons and links use icon-only labels (no text).
- Accordingly, buttons and links have a circular background shape.

### Color

- Light mode only; dark mode is not supported.
- Primary color: muted yellow-green.
- Secondary color: muted yellow.
- Lists are presented as plain lists, not cards.

### Logo

- Rigid, structured aesthetic.
- Conveys a sense of accounting-like precision and strictness.
